# GTA Alerts - Stable Map Version

This version removes Leaflet completely and uses an embedded OpenStreetMap iframe.

## Why

The previous map tile system was partially loading/overlapping on some browsers. This stable version avoids that issue.

## Features

- Professional light design
- Stable embedded map
- Filter buttons
- Clickable recent alert cards
- Alert details panel
- No map tile overlap/splitting problem
- No scroll-wheel map stealing

## Upload

Upload these files to the root of `Jtragas/gta-alerts` and replace the old files:

- index.html
- styles.css
- app.js
- README.md
- CNAME
- .nojekyll

After uploading, press Ctrl + F5 on the site.
